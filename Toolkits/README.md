# Tribal Toolkits

每个部族工具包都是人工筛选后的可能相关牌集合，不是最终牌表，也不是默认必留清单。

## 使用顺序

1. 新系列、补充产品或牌面/规则更新后，先更新对应工具包的系列快照、牌名、合法性、平台印刷、角色和备注。
2. 再从工具包中挑选本次可能用上的牌，写入构筑种子或候选池。
3. 未选条目保留为备查，不自动进入最终套牌。
4. 构筑输出仍须执行 `tools/mtg_tool.py validate`；工具包本身不替代赛制门禁。

`tribal_toolkit.template.json` 是新工具包模板。实例目录至少包含一个 `toolkit.json`；若有当前构筑，使用 `selected_seed.txt` 明确记录本次选用的子集。
