# Quintorius Kand V5（倾探链保真 + 隔间双门分期引擎 / Explorer / MTGA BO1）

基准日期：`2026-08-08`。模式 B 迭代（基于 V4）。本轮按用户方向考察**隔间（Room，DSK 双门结界）**机制：先施放一扇门进场、之后任意回合以特殊动作付另一扇门的费用解锁——典型的"分阶段付费"；且隔间为 split 牌，**牌面法术力值 = 两门费用之和**（赛制内全部隔间合并值 ≥5），天然满足倾探 4 保真约束。

一句话玩法（不变）：≤4 费非地牌只有 8 张复制人，康德 −3 倾探 4 必中复制人链式烧血；V5 在 V4 预兆/预示互动基础上，用两张隔间提供**放逐区引擎与触发翻倍放大器**。

## 入选隔间与烧血联动（关键结算）

康德的烧血触发 = "当你从放逐区施放咒语时"（触发式异能，属于鹏洛客永久物）。

- **焦毁门厅 // 扭曲虚空 Charred Foyer // Warped Space**（合并 MV 10）
  - 门厅 `{3}{R}`：每个维持放逐牌库顶、本回合可使用——**从放逐区施放即触发全体康德烧血**，是每回合一次的引擎脉冲（翻到地使用不触发，但不亏牌）。
  - 扭曲虚空 `{4}{R}{R}`：**每回合一次，你从放逐区施放的咒语可付 {0}** ——预示过的末日劫难、历险本体、门厅放逐的牌、康德 −6 放逐的坟场牌全部可能免费施放；免费施放照样触发烧血，等于每回合白赚 2×康德数 点伤害。
- **镜厅 // 破碎境域 Mirror Room // Fractured Realm**（合并 MV 10）
  - 镜厅 `{2}{U}`：造己方生物的复制衍生物（复制飞龙/食肉龙/镜壳蟹；**不能复制鹏洛客康德**，仅前期过渡）。
  - 破碎境域 `{5}{U}{U}`：**己方永久物的触发式异能额外触发一次** ——康德烧血翻倍（每张康德每次放逐区施放烧 4）、食肉龙倾探翻倍（一次倾探 5 翻两次）、门厅放逐、末日劫难触发烧血全部翻倍，是组合技的线性放大器。

## 留牌指引与打法要点

- 必留：康德或元素杰作珍宝加速 + 2 地以上；对快攻留焦热撕咬/扮炫/末日劫难。
- **开门顺序**：焦毁门厅优先进场（每维持脉冲滚资源），扭曲虚空在有放逐区牌可施放时解锁；破碎境域只在已有康德/食肉龙场面时值得付 7 费解锁。
- **免费优先级**（扭曲虚空每回合一次）：免费末日劫难扫场 > 免费历险/预兆本体 > 门厅放逐的大哥。
- **触发 budget**：扭曲虚空免费施放与门厅脉冲都发生在自己回合；结束步骤异能产生的法术力（无）不跨步骤，本套无此类冲突。
- **两个独立赢点**：①倾探链 + 破碎境域翻倍烧穿；②预兆飞龙群 + 镜壳蟹物理终结，末日劫难清通道。
